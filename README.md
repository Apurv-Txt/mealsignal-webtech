# MealSignal

MealSignal is a full-stack meal planning and feedback platform for hostel messes, tiffin providers, and small caterers.

## Source download

Download and extract [MealSignal-source-code.zip](MealSignal-source-code.zip), then follow the README inside the archive for setup. The archive includes the Next.js and Supabase source, but excludes local environment secrets, dependencies, build caches, evidence screenshots, and the course report.

## Technology

- Next.js 16 App Router and React 19
- TypeScript
- Supabase Auth and PostgreSQL with Row Level Security
- Next.js Route Handlers
- Optional OpenAI-compatible API for feedback insights

## Demo notes

The analytics screen supports simulator-generated records, which are labeled in the interface. Feedback insights work in Local mode without an AI API key and switch to the configured compatible provider when a key is supplied. This repository contains source code; a live deployment is not configured.

The four UI evidence screenshots and the completed course report are maintained separately for the submission.
